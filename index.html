Security & Access Control

Basic security practices applied during deployment.

SSH Key Authentication

Connected to the Linux server using a private key instead of password-based SSH login.

Restricted SSH Access

Limited inbound SSH access to a specific public IP address through the EC2 Security Group.

HTTP Access

Allowed inbound HTTP traffic on port 80 so visitors could reach the test website.

This is a learning environment. HTTPS/TLS and production hardening have not yet been configured.

Real-World Troubleshooting

Investigating an issue, finding the cause, and verifying the fix.

Case Study · Apache

HTTP 403 Forbidden

Problem: A local HTTP request returned a 403 response after Apache was installed.

Investigation: Inspected the Apache error log and checked the web root directory.

Root cause: The web root did not contain an index.html file, and directory listing was disabled.

Resolution: Created a homepage at /var/www/html/index.html.

Verified: HTTP 403 → HTTP 200 OK
